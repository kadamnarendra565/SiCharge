# 🚀 Deploying SiCharge on Vercel with GitHub

Your local Git repository is completely initialized, all project files are committed to the `main` branch, and the `origin` is configured to:
`https://github.com/kadamnarendra565/SiCharge.git`

---

## ⚡ Step 1: Push Code to GitHub

You have 2 very easy ways to push your code:

### Method A: Double-Click the Helper Script
Simply double-click [`push_to_github.bat`](./push_to_github.bat) in this project folder. It will prompt you in your browser or terminal to authenticate with GitHub and push all files to `main`.

### Method B: Run from PowerShell / Terminal
```powershell
& "$env:USERPROFILE\.mingit\cmd\git.exe" push -u origin main
```
*(If prompted for password/token, enter your GitHub Personal Access Token or sign in via browser).*

---

## ⚡ Step 2: 1-Click Deploy on Vercel (Free)

1. Open your browser and go to: **[https://vercel.com/new](https://vercel.com/new)**
2. Sign in with your GitHub account (`kadamnarendra565`).
3. Under **"Import Git Repository"**, find and click **"Import"** next to **`SiCharge`**.
4. Leave all default settings as they are:
   - **Framework Preset**: *Other*
   - **Root Directory**: `./`
5. Click **"Deploy"**!

---
