# SiCharge — Silicon Carbide (SiC) Power Module for EV & Industrial Battery Systems
## Entrepreneurship Development (ED) Group Project • Experiment No. 04

An interactive web application and financial feasibility modeling tool built for the **Entrepreneurship Development (ED)** course.

---

## 🌟 Key Features & Sections

### 1. Interactive Break-Even & Financial Lab (Experiment 04)
- **Live Dynamic Sliders**: Fixed Costs (Prototyping, Pack Integration, Certification, Branding), Variable Costs per unit (SiC MOSFET chips, Assembly & QC, Packaging), Unit Selling Price, and Sales Run-Rate.
- **Mathematical Accuracy**:
  - Contribution Margin = $\text{Selling Price} - \text{Variable Cost} = ₹15,000 - ₹10,000 = ₹5,000$ ($33.3\%$).
  - Break-Even Point (BEP) = $\frac{\text{Fixed Costs}}{\text{Contribution Margin}} = \frac{₹4,50,000}{₹5,000} = 90\text{ units}$.
  - Monthly Run-Rate Profit at 150 units = $(₹15,000 - ₹10,000) \times 150 = ₹7,50,000/\text{month}$.
  - Calculated Payback Period $\approx 0.6\text{ months}$ ($18\text{ days}$).
- **Interactive Chart.js Visualizer**: Displays dynamic Cost-Volume-Profit lines, break-even crossover point, and operating profit zones.

### 2. Interactive Business Model Canvas (BMC)
- Complete 9-building block canvas with color coding, domain filter buttons (Aerospace, Data Centers, EV & Rail, Medical), and click-to-expand deep dive modal insights.

### 3. Target Industry Matrix & Impact Potential
- Interactive filter for **Ready-to-Implement** (Drones, Solar/Wind Inverters, Off-Grid Water Purification, Smart Appliances) and **Emerging Horizons** (800V EVs, High-Speed Rail, AI Hyperscale Data Centers, Aviation, Defence, Mining, Marine).
- Interactive technical comparison between conventional Silicon (Si) IGBTs and Silicon Carbide (SiC) MOSFETs.

### 4. Supply Chain & 7 Risk Factors Playbook
- Visual stages: Raw Materials (\$1,500/ton $\approx$ ₹1,44,000/tonne), R&D Patent Strategy, Fabless Assembly Model, and Market Scale.
- 7 Critical Risk Factors with concrete mitigation strategies (optical testing, ESD transport, advance payments, HASS/HALT accelerated stress chambers).

### 5. Experiment 04 Formatted Worksheet
- Standard formatted assignment sheet ready for **One-Click Print / PDF Export**.

## 🚀 How to Run Locally

Open PowerShell or Command Prompt in this folder and run:

```powershell
python server.py
```

This launches a local preview server on `http://localhost:8000` and automatically opens your browser.

---

## 📄 Standalone Web Application

Double-click `index.html` to open directly in any modern browser without installing any server software or dependencies. All calculations, charts, and interactive matrices work 100% offline.
